# 🌙 Iqbal AI Bot

An elegant, interactive web application designed to explore the timeless verses of Allama Iqbal. Built with a minimalist aesthetic following the **60-30-10 color rule**, this bot allows users to search, filter by keywords, copy verses, bookmark favorites, and listen to audio poetry recitations.

---

## ✨ Features

- **Interactive Keyword Search:** Instantly discover verses related to categories like *Khudi (Selfhood)*, *Ishq (Love/Passion)*, *Shaheen (The Falcon/Vision)*, *Youth*, and *Khirad (Intellect)*.
- **Curated Poetry Database:** Handpicked Persian and Urdu masterpieces translated and transliterated for global accessibility.
- **60-30-10 Aesthetic Color Palette:** 
  - **60% Dominant:** Deep Midnight Slate (`#0F172A`) for an immersive, contemplative reading background.
  - **30% Secondary:** Rich Muted Indigo/Navy (`#1E293B` & `#334155`) for cards and structural UI elements.
  - **10% Accent:** Luminous Gold/Amber (`#F59E0B`) to draw focus to calls-to-action, active tags, and highlights.
- **Favorites & Bookmarking:** Save your most beloved verses for quick reflection.
- **One-Click Copy:** Easily copy Persian/Urdu scripts and English translations to your clipboard.
- **Audio Simulation:** Ambient audio recitation preview simulator for an enhanced spiritual and literary experience.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic and clean markup.
- **CSS3 / Tailwind CSS (CDN):** Modern utility-first styling for responsive design, smooth transitions, and glassmorphism accents.
- **JavaScript (ES6+):** Dynamic search filtering, state management for favorites, clipboard API integration, and interactive UI feedback.

---

## 🚀 Getting Started

No complex build steps or installations are required! Because it's built using standalone web technologies, you can run it instantly in any modern web browser.

### Running Locally

1. **Clone or Download** the project files to your local machine.
2. Ensure you have the main application file (e.g., `index.html` or `iqbal_bot.html`).
3. **Open the file** directly in your preferred web browser (Chrome, Firefox, Safari, Edge) by double-clicking it or dragging it into an open browser window.
